# 🐍 Desafios de Python - Curso em Vídeo

Repositório criado para armazenar e organizar a resolução de quase 100 exercícios práticos propostos pelo professor Gustavo Guanabara no curso de Python do canal Curso em Vídeo.

## 🎯 Objetivo do Projeto
Consolidar os fundamentos da programação, desenvolver o raciocínio lógico e dominar a sintaxe da linguagem Python através de desafios práticos do mundo real.

## 🗂️ O que foi aprendido até agora:
- **Mundo 1:** Instalação do ambiente, tipos primitivos, operadores aritméticos, manipulação de texto e estruturas condicionais (`if/else`).
- **Mundo 2:** Estruturas de repetição controladas e lógicas (`for` e `while`).

## 🛠️ Tecnologias Utilizadas
- Python 3
- VS Code 
- Git e GitHub para controle de versão

## 🚀 Como rodar os exercícios
1. Clone o repositório: `git clone https://github.com`
2. Entre na pasta do exercício desejado.
3. Execute o arquivo com: `python nome_do_arquivo.py`
